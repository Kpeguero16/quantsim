# QuantSim password blocklist
#
# What this is: a hand-curated list of weak password shapes that survive a
# 15-character minimum -- padded common words, keyboard walks, repeated
# fragments, and well-known phrases. Every entry is 15+ characters, enforced
# by a test; shorter entries are dead weight because the length rule already
# rejects them.
#
# What this is NOT: a verified breach corpus. It is a floor, not a survey.
# The stronger control is an online lookup against Have I Been Pwned's
# k-anonymity API, deferred with reasoning in SPEC.md 7. Extend this file
# freely -- entries are compared case-insensitively, one per line, and lines
# starting with # are ignored.
#
# Passwords containing the username, the email local part, or the service
# name are handled in code (blocklist.go), not here.
